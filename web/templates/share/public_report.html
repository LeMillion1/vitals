{# The document a doctor reads. Standalone on purpose: no base.html, no Tailwind, no Alpine, no HTMX, no /static, no script of any kind. The reason is the download button. This same markup is saved to disk and has to open offline from a double-click, and `tailwind.css` is a 300 KB link to /static that would be a dead reference the moment the file leaves the server. A side benefit is that the "a new arbitrary Tailwind class renders unstyled until the bundle is rebuilt" trap cannot reach this page. No dark theme, deliberately. This is a document that gets printed; a dark background looks broken on paper and in a PDF, and maintaining two themes inside inline CSS that also travels into a downloaded file is work with no reader on the other end of it. Fonts are system stacks only. The project's display faces carry no Cyrillic, and an offline file has nowhere to load a webfont from anyway. #} {{ t("doc.page_title") }}
